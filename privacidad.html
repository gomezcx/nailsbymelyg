Privacidad

Esta web pertenece a Nails by MelyG (Katy, Texas). Cuando reservas una cita, los datos que escribes (nombre, teléfono, correo y notas) se envían a Square, el sistema que uso para gestionar mi agenda y mis pagos, solo para crear y administrar tu cita.

Los datos de tu tarjeta los procesa directamente Square; esta web nunca los ve ni los guarda. Se usa la tarjeta solo según la política de cancelación que aceptas al reservar.

No vendo ni comparto tus datos con terceros para publicidad. Esta web guarda en tu navegador únicamente el idioma que elegiste.
